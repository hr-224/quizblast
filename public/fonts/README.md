# Self-hosted fonts

- **Lexend** (variable, latin + latin-ext) — headings, scores, PIN. © The Lexend Project Authors, SIL Open Font License 1.1.
- **Atkinson Hyperlegible** (400, 700; latin + latin-ext) — body text. © Braille Institute of America, SIL Open Font License 1.1.

Files are the WOFF2 subsets served by Google Fonts, hosted locally so school networks that block third-party font hosts still render correctly and students' browsers make no third-party requests.
